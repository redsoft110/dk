##### 描述
解剖技能提升武器伤害，提升挥击速度，并通过治疗技能增加绷带治疗的治疗量。解剖学和治疗技能达到60级或以上，玩家可以尝试用绷带治愈毒素，达到80级或以上时，两者都可以尝试复活死去的玩家。同时还能为玩家提供对流血或疾病效果的伤害抗性。
疗愈互动
尝试绷带治疗需要最低解剖技能60
尝试绷带复活需要最低解剖技能80
拥有100治疗和至少80解剖学的玩家，始终有100%的几率用绷带复活目标
绷带治疗量为（（治疗技能 / 100） * （（随机值40到60） * （1 + （0.2 * 解剖技能 / 100）））
